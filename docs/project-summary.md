# Project Summary

## 문제 상황

강의 영상 제작은 PPT 분석, 스크립트 작성, 녹음, 편집, 자막 제작이 모두 필요합니다. 슬라이드가 조금만 바뀌어도 작업을 반복해야 하고, 강사마다 설명 깊이와 스타일이 달라 콘텐츠 품질 편차가 생길 수 있습니다.

## 해결 방향

PPT 파일을 입력으로 받아 강의 영상 제작 과정을 Agent 그래프로 자동화했습니다. 각 노드는 슬라이드 파싱, 외부 검색, 내용 생성, 스크립트 작성, 음성 변환, 영상 합성, 퀴즈 생성처럼 명확한 역할을 담당합니다.

## 구현 포인트

- LangGraph StateGraph로 전체 파이프라인 구성
- PPT 슬라이드별 텍스트, 표, 이미지, 스냅샷 추출
- Tavily 검색으로 슬라이드별 부연 설명 정보 수집
- GPT-4o-mini로 요약문과 발표 대본 생성
- GPT-4o-mini-TTS로 음성 생성
- FFmpeg로 MP4 영상 병합 및 자막 합성
- ChromaDB와 OpenAI Embeddings로 맥락 기반 퀴즈 생성
- Gradio UI로 비개발자도 사용할 수 있는 화면 제공

## 고도화 내용

- 사용자가 원하는 강의 톤과 음성을 선택할 수 있도록 프롬프트 입력 추가
- 생성 대본을 사용자가 피드백으로 수정할 수 있는 구조 도입
- 자막과 핵심 키워드 하이라이트를 영상에 합성
- 슬라이드 맥락 기반 객관식 퀴즈 생성 기능 추가

## 기대 효과

- 강의 영상 제작 시간을 수시간/수일 단위에서 수분 단위로 단축
- 강사별 품질 편차를 줄이고 일관된 설명 흐름 제공
- 사내 교육, 제품 매뉴얼, 대학 강의 보조 자료 등 다양한 교육 콘텐츠에 확장 가능
