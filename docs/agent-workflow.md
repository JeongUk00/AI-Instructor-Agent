# Agent Workflow

## Flow

1. 사용자가 PPTX 파일, 강의 톤, TTS 음성을 입력합니다.
2. Agent가 모든 슬라이드를 순회하며 텍스트, 표, 이미지, 슬라이드 스냅샷을 추출합니다.
3. 추출한 슬라이드 내용을 Vector DB에 저장합니다.
4. 각 슬라이드 제목을 기반으로 Tavily 검색을 수행해 부연 설명 자료를 수집합니다.
5. LLM이 슬라이드 정보와 검색 결과를 바탕으로 페이지 설명문을 생성합니다.
6. 설명문을 기반으로 강의 스크립트, 핵심 키워드, 강조 시점을 JSON 형식으로 생성합니다.
7. 사용자 피드백이 있으면 스크립트를 다시 수정합니다.
8. 스크립트를 음성으로 변환하고, 슬라이드 이미지와 합성해 개별 MP4를 생성합니다.
9. 자막과 핵심 키워드 하이라이트를 영상에 합성합니다.
10. 모든 슬라이드 처리가 끝나면 복습 퀴즈를 생성하고, 개별 영상을 하나의 최종 강의 영상으로 병합합니다.

## State Design

Agent의 State에는 입력 경로, 작업 디렉터리, 사용자 프롬프트, 현재 슬라이드 인덱스, 슬라이드 파싱 결과, 검색 결과, 페이지 요약, 강의 스크립트, 음성/영상 경로, Vector DB, 퀴즈 결과, 자막 데이터가 포함됩니다.

## User Interface

Gradio 화면에서는 PPT 업로드, 강의 톤 입력, TTS Voice 선택, 최초 영상 생성, 피드백 반영 재생성, 최종 영상 미리보기/다운로드, 복습 퀴즈 풀이를 제공합니다.
